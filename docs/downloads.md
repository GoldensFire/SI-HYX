# Загрузка и сетевые обрывы

Полный диапазон от нуля до длительности ролика скачивается обычным загрузчиком
yt-dlp. FFmpeg используется для настоящего отрезка; для нарезки предпочтителен
отдельный `bin/ffmpeg7`. Оба сетевых входа FFmpeg получают параметры
переподключения и ограничение ожидания чтения. Обычный конец файла не вызывает
повторного подключения.

Перед статусом «Готово» программа проверяет результат через ffprobe: наличие
ожидаемых дорожек и длительность каждой дорожки. Длительность звука может быть
меньше длительности видео, даже если общая длительность MP4 выглядит правильной.
Допускается небольшая разница из-за округления и нарезки по ключевым кадрам.
Длительности читаются из полей потока, временной базы и тегов DURATION.

Обрыв чтения FFmpeg, неудачный код завершения и неполный результат не считаются
успешной загрузкой. При сетевом сбое или неполном файле выполняются максимум
две дополнительные попытки. Неполный готовый файл сохраняется с суффиксом
`.incomplete` (при нескольких попытках — `.incomplete-1` и далее), чтобы yt-dlp
не пропускал его как уже скачанный. Файлы сохраняются для диагностики;
удалить их можно вручную после успешного скачивания.

Команда «Скачать заново» сохраняет диапазон и серию выбранного задания,
применяет текущие качество, прокси и cookies и принудительно перезаписывает
результат. Если прежняя загрузка ещё работает, новая начинается
после завершения старого потока. Остановка в Windows завершает собственное
дерево процессов yt-dlp, включая его FFmpeg/Deno. Поздние сигналы старого задания
не меняют состояние нового.

Запрос метаданных имеет ограниченное ожидание и повторяется при сетевом сбое.
Причина ошибки сохраняется в консоли. При замене ссылки старый запрос
отменяется; его данные не подменяют длительность нового ролика.

## zapret-discord-youtube

Этот [проект Flowseal](https://github.com/Flowseal/zapret-discord-youtube)
использует системный перехват трафика WinDivert. Это не браузерный PAC-прокси;
при такой установке поле «Прокси» в SI-HYX обычно оставляют пустым.

Браузер и загрузчик могут использовать разные протоколы и DNS. В штатной
[стратегии](https://github.com/Flowseal/zapret-discord-youtube/blob/main/general.bat)
отдельно настроены UDP 443 и TCP 443. yt-dlp/FFmpeg используют HTTPS по TCP;
важна работа этой стратегии для youtube.com и googlevideo.com, а также
системного DNS. Включение защищённого DNS только в браузере не меняет DNS
загрузчика. Внешние настройки zapret программа сама не изменяет.

Код 10054 означает сброс соединения. По нему нельзя однозначно определить,
кто сбросил соединение: сервер, провайдер или промежуточный сетевой фильтр.
При повторяющихся обрывах проверяют службу и выбранную стратегию zapret
согласно его README; сравнительная загрузка через другую сеть или системный
VPN помогает отделить сетевой сбой от ошибки приложения.
