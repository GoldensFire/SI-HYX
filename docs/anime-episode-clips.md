# Отрывки серий в аниме-паке

Один вопрос — случайный **15-секундный** участок существующей серии выбранного
аниме с японским аудио. Исходник должен иметь фактическую высоту **≥1080p**;
готовый ролик сжимается в **720p AV1 + Opus** с общими CRF/пресетом генератора.
OP/ED исключаются по таймкодам источника; без таймкодов пропускаются первые
и последние 15% серии, максимум по три минуты.

## RU-sub источники и автоматический выбор

Каталоги **AnimeGO, YummyAnime и AnimeLIB** ищутся одновременно. Привязка —
точный MAL/Shikimori/AniList ID; без ID требуется совпадение названия и
доступного года. Соседние сезоны, озвучки и дробные номера серий не принимаются.
Списки API читаются с пагинацией. Для выбранной серии сохраняются все команды
субтитров и альтернативы, а не только первый найденный релиз.

Приоритет плееров: **CVH → Aniboom → AnimeLIB native → Alloha**.
Внутри одного плеера выбирается максимальное подтверждённое разрешение;
при равенстве — больший bitrate. Ошибка плеера, плохое качество, отсутствие
японского аудио или неработающие RU-субтитры переключают на следующую
альтернативу. Kodik не запрашивается: его 720p не подходит. Случайная серия
берётся только из фактических списков; проверяются до трёх серий тайтла.

CVH перечисляет все subtitle-релизы своего публичного playlist API, включая
команды, которых нет среди кнопок сайта. Aniboom читает опубликованные
HLS/DASH из `video[data-parameters]`. AnimeLIB использует `episodes`,
`players`, `video.quality[].href`, `subtitles[].src` и `constants.videoServers`;
URL качества конструируется только из опубликованного пути и сервера.

HLS master раскрывается по `RESOLUTION`, отдельная аудиогруппа сохраняется.
DASH MPD ограничивается выбранным video Representation, аудио и удалённый
BaseURL сохраняются. Отфильтрованный manifest передаётся через временный
локальный HTTP-сервер: заголовки CDN сохраняются и при кодировании.
Затем **ffprobe измеряет реальную высоту видеодорожки**:
метка плеера, имя файла или путь `/1080/` не являются подтверждением.
Поток 720p под меткой 1080p отбрасывается; апскейла в 1080p нет.

Уже встроенные RU-субтитры не накладываются повторно. Отдельные русские
субтитры native/Alloha обрезаются по выбранному фрагменту и вшиваются;
неудачное вшивание переключает на другой источник.

## Аккаунт AnimeLIB и Alloha

Публичные релизы проверяются без ключей SubDL/Jimaku. Некоторые native-видео
AnimeLIB доступны только аккаунту: необязательный Bearer-токен вводится в
**Настройки → Ключи API → AnimeLIB**. Используется доступ, предоставленный
этому аккаунту. Токен хранится в общем месте ключей, передаётся только API
AnimeLIB и не записывается в SIQ или метаданные ролика.

Alloha открывается в фоновом установленном **Edge или Chrome** через
Playwright. Дополнительный браузер не скачивается. Ответ `bnsi` привязывается
к выбранному subtitle-переводу, сохраняются русские captions и CDN fallback.
Локальный временный HLS-мост сохраняет живую сессию и обновляемые заголовки
во время ffprobe/FFmpeg; одноразовый `borth` не воспроизводится повторно.
Закрытие тайтла, таймаут и Stop закрывают браузер и мост. Недоступный Alloha
отбрасывается по тем же правилам, что остальные источники.

## Резерв Kuhi и дополнительные субтитры

После RU-sub источников остаются все десять native-провайдеров Kuhi
и резервный Miruro pipe. Предпочтение: MKissa raw → softsub → hardsub;
dub не допускается. **К резерву применяется тот же порог ≥1080p.**
AniList ID берётся из карточки или AniZip; RU-каталоги могут работать по
MAL ID даже без AniList-маппинга. AniLiberty и Anivexa не используются.

Галочка «Русские субтитры» задаёт приоритет RU в готовом видео. Принимаются встроенные
RU либо отдельная дорожка **самого выбранного видео**; иностранная дорожка
переводится настроенным Gemini без изменения её таймкодов. Если русской дорожки
или успешного перевода нет, используются английские субтитры самого видео,
включая уже вшитые. Видео без подходящей дорожки заменяются. В метаданных
`ru_subtitles` означает фактические RU; `subtitle_language` хранит язык показанных
субтитров, а `subtitle_source_language` — язык исходной отдельной дорожки.
SubDL/Jimaku остаются
источниками вопросов-диалогов: совпадение тайтла и номера серии не доказывает
совпадения монтажа, поэтому их отдельные релизы для отрывков не подставляются.
RU-субтитры трёх русских источников используются независимо от галочки.
WebVTT с короткими `mm:ss.mmm` таймкодами разбирается наряду с SRT/ASS.
Отрывок с отдельной дорожкой выбирается среди участков с репликами; сабы
обрезаются по обеим границам и вшиваются при единственном кодировании AV1.
Перед вшиванием видеочасы обнуляются после сетевого seek.

Kuhi перенесён из [aryaniiil/anime-api](https://github.com/aryaniiil/anime-api)
на коммите `d9a785ad030d6fc6a8ad709291be9612c864449e`; MIT-лицензия сохранена
в `si_hyx_parts/kuhi/LICENSE`. Форматы CVH/Aniboom сверены с
[anime-dl-core](https://github.com/ialakey/anime-dl-core), YummyAnime/Alloha —
с [YummyTV](https://github.com/Helandy/YummyTV/blob/main/docs/alloha-player.md)
и публичными ответами сервисов. Playwright использует упакованный драйвер;
отдельные сервер Kuhi, FastAPI и Node.js для каталога не нужны.

## Лимиты, выходной файл и проверка

FFmpeg читает выбранные HLS/DASH-сегменты либо диапазоны MP4 с нужными
Referer, Origin и User-Agent. MP4 без HTTP Range отбрасывается до ffprobe.
Полная серия на диск не загружается. Японская дорожка выбирается по
`ja/jpn`; явно другой язык исключается. Без тега допускается raw/sub.
После кодирования проверяются обе дорожки и длительность **14,5–15,75 с**.

Число одновременно готовящихся тайтлов следует настройке параллелизма;
AV1 по-прежнему ограничен двумя кодировщиками. Общий HTTP ограничен восемью соединениями,
тремя запросами в секунду на хост, 300 запросами и четырьмя минутами на
тайтл. Ответ каталога/manifest ограничен 4 МиБ; HLS-мост Alloha — четырьмя
одновременными запросами и 32 МиБ на ответ. Stop отменяет HTTP и завершает
FFmpeg через раннеры генератора. Ограничение частоты относится к началу
запроса, а не к чтению всего ответа: медленный CDN не запирает свой хост.
Каталоги Kuhi ищутся во время проверки RU-источников; готовые провайдеры
отдаются порциями, без ожидания зависших. Остальные отменяются только после
успешного ролика или завершения тайтла. До трёх альтернатив проверяются
ffprobe параллельно; реальные высота, аудио и приоритет качества сохраняются.
PyInstaller включает Playwright driver.

В `episodes.json` внутри SIQ сохраняются AniList ID, серия, начало,
длительность, провайдер, команда релиза, реальная исходная высота, выходные
720p и наличие RU-субтитров. Подписанные URL и заголовки туда не попадают.
Для отдельных дорожек также записываются исходные и русские реплики и их
таймкоды внутри отрывка (`subtitle_cues`), язык и способ получения.

| Задача | Модуль в `si_hyx_parts/animepack/` |
|---|---|
| Каталоги и идентичность | `episode_ru_catalog.py`, `episode_ru_animego.py`, `episode_ru_yummy.py`, `episode_ru_animelib.py` |
| Плееры и отмена | `episode_ru_players.py`, `episode_ru_client.py` |
| Alloha и HLS-мост | `episode_ru_alloha.py`, `episode_alloha_proxy.py` |
| HLS/DASH и разрешение | `episode_stream_quality.py`, `episode_media.py`, `episode_manifest.py` |
| Серии, OP/ED и запись | `episode_sources.py`, `episode_generation.py` |
| Синхронные субтитры и перевод | `episode_captions.py`, `episode_caption_text.py` |
| Готовые провайдеры и альтернативы | `episode_fallback.py`, `../kuhi/batches.py` |

Тесты проверяют формы API, все команды субтитров, пагинацию, порядок плееров,
ложную метку 1080, многовариантные HLS/DASH, сохранение аудио, откат после
ошибки субтитров и закрытие временного сервера manifest. `test_episode_ffmpeg`
нарезает настоящий локальный 1080p HLS/MP4/DASH, включая отфильтрованные
manifest с отдельным аудио и обязательными CDN-заголовками. `test_episode_alloha_browser`
открывает локальный плеер настоящим Edge/Chrome и проверяет передачу сессии
и закрытие после истечения дедлайна.

Ручной сетевой стенд: `python tools/episode_probe.py --count 5`.
Он сохраняет SIQ, журнал и `report.json` в `artifacts/episode-live-check`;
поддерживает `--ids` и `--out`. Доступность CDN зависит от сети и региона.
Точный прогон текущих сохранённых настроек: `python tools/episode_probe.py
--current-settings --count 24 --out artifacts/episode-check`. Настройки и
ключи пользователя не изменяются; копия настроек в отчёте не содержит ключей.
Проверка готового SIQ: `python tools/episode_pack_audit.py PACK.siq --out
artifacts/episode-audit --ocr`: ссылки вопросов, декодирование всех дорожек,
AV1/Opus, длительность, высота, видимые RU-субтитры и совпадение реплик с
записанными таймкодами; кадры для просмотра сохраняются рядом с JSON.

## Подключение AnimeGO.online

AnimeGO использует `https://animego.online`: поиск DLE через `index.php`,
проверка русского и оригинального названий на странице, затем публичный
`engine/ajax/controller.php?mod=player`. Серии берутся из фактического
плейлиста CVH или Alloha; количество в карточке не разворачивается в `1..N`.
Сохраняются только релизы с русскими субтитрами, без Kodik и озвучки.
Alloha открывается внутри iframe: отдельная страница вызывает ложное сообщение
о недоступности в регионе. Источник, тайтл и причина пустого результата
теперь указываются в журнале; сетевые ошибки не маскируются под отсутствие серий.
