# Отрывки серий в аниме-паке

Во вкладке генератора включите «Отрывки серий» и задайте их долю в составе.
Один вопрос — случайный 20-секундный участок случайной существующей серии
выбранного аниме. Используются общие настройки качества видео AV1 и Opus.

«Русские субтитры» по умолчанию выключены. При включении нужны существующие
ключи SubDL и/или Jimaku. SubDL ищет русский файл по точному сезону и серии
из AniZip. Если файла нет, Jimaku ищет по AniList ID и номеру серии;
японские реплики переводит уже настроенный Gemini. Субтитры обрезаются по
границам фрагмента, сдвигаются к нулю и вшиваются. Ошибка или отсутствие
субтитров оставляет обычный видеовопрос.

## Источники и ограничения

Нативный слой перенесён из [Kuhi/anime-api](https://github.com/aryaniiil/anime-api)
на коммите `d9a785ad030d6fc6a8ad709291be9612c864449e`.
Лицензия MIT и атрибуция сохранены в
[si_hyx_parts/kuhi/LICENSE](../si_hyx_parts/kuhi/LICENSE).
Сервер FastAPI и Node.js для работы не нужны.

Подключены все десять native-провайдеров upstream: MKissa, AniNeko, AniZone,
AniKoto, ReAnime, AniWaves, Kaa, AniBD, AnimeGG, AnimeOnsen. Каждый доступный
провайдер участвует в параллельном поиске; успешные альтернативы сохраняются
для повторной попытки после ошибки видео. Сначала пробуются MKissa raw,
затем softsub, затем hardsub. После исчерпания native-источников работает
резервный Miruro pipe из Kuhi со всеми его sub-провайдерами и зеркалами.
Dub не запрашивается и не принимается. AniLiberty и Anivexa не используются.

AniList ID берётся из карточки SI-HYX или существующего маппинга AniZip.
Серия выбирается из фактических списков источников. OP/ED исключаются по
таймкодам источника, включая VTT chapters; при отсутствии таймкодов не
используются первые и последние 15% серии, максимум по три минуты.

FFmpeg читает удалённые HLS/DASH-сегменты либо диапазоны MP4 с нужными
Referer, Origin и User-Agent. MP4 без поддержки HTTP Range отбрасывается.
Полная серия на диск не загружается. До нарезки ffprobe выбирает японскую
аудиодорожку; явно другой language tag исключается. Дорожка без языкового
тега допускается только из raw/sub-источника. После нарезки проверяются
видео, аудио и длительность 19,5–20,75 секунды.

Одновременно обрабатываются до двух тайтлов; HTTP ограничен восемью
соединениями, тремя запросами в секунду на хост (AniList — одним),
300 запросами и четырьмя минутами на native-поиск и нарезку тайтла. Один HTTP-ответ ограничен 4 МиБ,
подписанные stream-ссылки кешируются на 45 секунд. Stop отменяет native
запросы и завершает FFmpeg через существующие раннеры генератора.
PyInstaller собирает динамически импортируемые провайдеры и MIT-лицензию.

Внутри `.siq` файл `episodes.json` хранит AniList ID, серию, начало,
провайдера и наличие вшитых RU-субтитров. Подписанные URL и заголовки
авторизации в пак не записываются.

## Карта реализации и проверка

| Задача | Модуль |
|---|---|
| Общий native race и резерв | `si_hyx_parts/kuhi/_race.py`, `legacy.py`, `client.py` |
| Сетевые лимиты и отмена | `si_hyx_parts/kuhi/_transport.py` |
| Маппинг, серии, окна OP/ED | `si_hyx_parts/animepack/episode_sources.py` |
| FFmpeg и проверка дорожек | `si_hyx_parts/animepack/episode_media.py` |
| Повторные попытки и запись результата | `si_hyx_parts/animepack/episode_generation.py` |
| SubDL → Jimaku, сдвиг и вшивание | `si_hyx_parts/animepack/episode_subtitles.py` |
| Настройки интерфейса | `si_hyx_parts/animepack_tab/episode_controls.py` |

Тесты `test_kuhi_native`, `test_kuhi_fallback`, `test_animepack_episode`,
`test_animepack_episode_subtitles` проверяют native-экстракторы, выбор,
отмену, лимиты и субтитры. `test_episode_ffmpeg` поднимает локальную раздачу
HLS/MP4/DASH, проверяет диапазоны и выбранные сегменты настоящим FFmpeg,
включая HLS-сегменты с расширением `.jpg` и вшивание русских субтитров.

Для ручной проверки сети: `python tools/episode_probe.py --count 5`.
Стенд запускает обычный генератор и сохраняет `.siq`, журнал и `report.json`
в `artifacts/episode-live-check`. Можно указать `--ids` и `--out`.
