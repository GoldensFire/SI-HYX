# Задержки генерации и восстановление окна

В живом процессе 1 октября 2026 года обнаружены три проблемы.

- Поток кандидатов находился внутри `db_json._dump`, вызванного из
  `_load_franchise_indexes`. Каждый небольшой ответ API приводил к записи
  всей базы; размер файла на тот момент составлял 399 542 551 байт.
- Главный поток Qt периодически находился внутри `RecentFilesStrip._scan`.
  Таймер каждые пять секунд обходил папку загрузок, проверял все файлы и
  сортировал их по времени. Это выполнялось даже при свёрнутом окне.
- У главного окна одновременно были обычное состояние Qt, размер 720×480
  и геометрия `(-25593, -25570)`. Обычная геометрия также содержала эти
  координаты. При масштабе экрана 125% это соответствует служебной позиции
  свёрнутого окна Windows около `(-32000, -32000)` с поправкой на рамку.
  Простого восстановления состояния было недостаточно: пришлось вернуть
  положение окна явно. Точный порядок событий Windows, испортивший обычную
  геометрию, по имеющимся логам восстановить нельзя.

`generation_checkpoint` откладывает промежуточные записи во время отбора.
Данные сохраняются после завершения производителя кандидатов и загрузчиков,
в том числе при отмене и исключении. При ручном обновлении базы прежние
контрольные точки остаются. Принудительное завершение процесса до этой записи
может потерять новые метаданные текущего отбора; уже сохранённая база не меняется.

`recent_files_scan` обходит каталог в рабочем потоке. Используются `scandir`,
одна проверка метаданных и выбор 30 последних файлов без сортировки всего
каталога. Повторные запросы объединяются, результаты старой папки отбрасываются.
Скрытая лента и свёрнутое окно не запускают периодический обход.

`window_visibility` хранит последнюю доступную позицию. Служебная геометрия
свёрнутого окна не запоминается; проверяются и Qt, и `IsIconic` Windows.
При раскрытии/активации окно возвращается в доступную область, при отключении
монитора — на оставшийся экран. Отрицательные координаты других мониторов
допустимы. Намеренное сворачивание не отменяется.

Отдельно исправлена потеря `ru_popularity` при копировании отложенной манги:
повторная попытка должна сохранять ту же шкалу узнаваемости.

Проверки: `test_generation_checkpoints.py`, `test_recent_files_scan.py`,
`test_window_visibility.py`, `test_animepack_candidate_reserve.py`.
