# Karaoke Rounded

Derived from [Nunito](https://github.com/googlefonts/nunito), instantiated
at weight 900 (Black). The family and PostScript names and bold style flags
are adjusted so libass can select the bundled static face consistently.
Distributed under SIL Open Font License 1.1; see OFL.txt for attribution
and the complete licence. FontTools is used only when preparing this asset;
it is not an application dependency.

# AMV text fonts

This folder is also the `fontsdir` of project text in the montage
(`montage_project` burns ASS with it), so the AMV styles in
`docs/amv-styles` find these faces without installing them. They are free
look-alikes of the faces used in the reference edits; files are unchanged
upstream static releases.
