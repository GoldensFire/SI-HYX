# SI-HYX

Медиа-комбайн под Windows: скачивание видео и аудио через yt-dlp, перекодирование
в AV1, конвертация изображений, монтаж, фоторедактор с нейросетями и инструменты
для паков SIGame (`.siq`).

Текущая версия — **0.6.0**.

## Скачать

Во вкладке **[Releases](../../releases)** скачайте архив `SI-HYX-v…-full.zip`,
распакуйте и запустите `SI-HYX.exe`. Устанавливать ничего не нужно: ffmpeg, yt-dlp
и deno лежат в `bin/`, нейросети — в `models/`.

Архив `…-update.zip` и `manifest.json` нужны программе для автообновления.

## Возможности

- **Обработка** — видео в AV1 (SVT-AV1), нормализация громкости и фейды,
  изображения в AVIF/WebP/PNG/JPG/ICO с лимитом размера.
- **Загрузчик** — видео и аудио по ссылке (YouTube, TikTok, Instagram и др.):
  качество, обрезка по таймингам, субтитры, «только аудио».
- **Монтаж** *(бета)* — покадровая обрезка по звуковой волне, Smart Cut,
  кадрирование, наложение картинок и текста, привязка к движущемуся объекту
  (DyHiT), удаление объектов с видео (LaMa).
- **Фото** — кисть, фигуры, текст, кадрирование, поворот; удаление объектов (LaMa)
  и фона (RMBG-2.0); склейка нескольких фото.
- **Base64** и **Промпт** — кодирование файлов и менеджер заготовок.
- **Генерация аниме-пака** *(экспериментальная)* — собирает готовый `.siq`:
  песни, ролики, кадры и кадры с эффектами, персонажи, манга, арты, анаграммы,
  вопросы по сюжету (Gemini), сакуга. Тайтлы — из Shikimori или списков
  MAL/Shikimori/AniList, сложность — по узнаваемости. Порт генератора
  [ASPG](https://github.com/Leleath/aspg) (Leleath, MIT) с разрешения автора.
- **Апгрейд пака** *(экспериментальная)* — дорабатывает готовый `.siq`: варианты
  названий и постеры с Shikimori, спецвопросы → обычные, сжатие медиа, уборка
  пустых вопросов и лишних файлов. Исходный пак не меняется.
- **SiQuesterHYX**, **ShikimoriHYX**, **ЛидербордHYX**, **Collab**
  *(экспериментальные)* — просмотр `.siq`, поиск аниме и манги, рекорды,
  совместная работа над паком.

Экспериментальные вкладки включаются в **⚙ Настройках**. Там же ключи API
(Gemini, Pixiv, Cloudflare, TMDB и др.), обновление yt-dlp и сервер для
браузерного расширения, которое отправляет ссылку со страницы в «Загрузчик».

## Сборка из исходников

Нужен Python 3.10+:

```bash
pip install -r requirements.txt
python main.py
```

Сборка `.exe` — `build.bat` (по `SI-HYX.spec`). Папки `bin/` и `models/` в
репозиторий не входят из-за размера: возьмите их из релиз-архива или соберите сами.

- `bin/`: [ffmpeg/ffprobe](https://www.gyan.dev/ffmpeg/builds/),
  [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases/latest),
  [deno](https://github.com/denoland/deno/releases).
- `models/`: `lama_fp32.onnx` (LaMa), `model_uint8.onnx` (RMBG-2.0) и
  необязательный `dyhit.onnx` (трекер; экспорт —
  [`tools/export_dyhit_onnx.py`](tools/export_dyhit_onnx.py)). Без моделей
  остальная программа работает как обычно.

Тесты и проверка правил кода:

```bash
python -m pytest
python tools/check_hygiene.py
```

Карта модулей — в [CODE_MAP.md](CODE_MAP.md).
